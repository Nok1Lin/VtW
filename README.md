# VtW · Visit the World

个人的「世界足迹 + 圣地巡礼 + 旅行规划」单页 Web 应用，无需构建工具，直接在浏览器（推荐 Microsoft Edge）打开即可使用，所有个人编辑记录自动保存在本地 `localStorage` 并支持 JSON 导入/导出备份。

## 核心功能

- **🗺️ 全球足迹与渐进下钻地图**：
  - 默认高清中文底图（Google 2x 中文底图，自动降级至高德 2x 中文并自动对大陆坐标执行 WGS-84 → GCJ-02 对齐）。
  - 点亮已到访国家和中国 34 个省级行政区；支持点击国家下钻查看一级行政区与主要城市。
  - **日本 9 大地方 × 47 都道府县真实行政轮廓**（北海道 / 东北 / 关东 / 中部·北陆 / 近畿·关西 / 中国地方 / 四国·濑户内 / 九州地方 / 冲绳），点击片区即可逐级聚焦并查看当地手账。
- **✦ 圣地巡礼 & 主题心愿单**：
  - 内置 7 条主题线（哥特 / 西幻 / 巨构 / 神代 / 奇观 / 生灵 / 圣地）纯色节点标记与底部图例快筛。
  - 接入 Anitabi 动画原画机位对比、Bangumi 评分、实景图库、Google 街景直达，以及按春/夏/秋/冬/当月最美筛选的季节灵感条。
- **🍜 美食 & 🎁 纪念品手账**：按国家/片区/城市聚合必吃美食、伴手礼与避坑记录，支持打勾「已吃/已入」及新增个人手账词条。
- **🧭 路线与筹备工作台**：侧边栏「我的路线」可展开切换「2027 暑假 · 亚欧非环线」与各自定义规划路线，并配套 TODO、装备清单、负重模拟、预算与城市 Markdown 攻略。

## 本地打开

- 直接双击或使用 Microsoft Edge 打开根目录下的 [`VtW.html`](VtW.html)。
- 若部署静态站点，可使用 [`travel-site/dist/`](travel-site/dist/) 目录（入口为 [`travel-site/dist/index.html`](travel-site/dist/index.html)）。

## 目录结构

```text
VtW/
├── VtW.html                  # 主入口（本地 file:/// 直接打开）
├── HANDOFF.md                # 开发交接与功能记录
├── README.md                 # 项目说明
├── 城市攻略/                  # 城市 Markdown 攻略文件（VtW.html 直接引用）
├── travel-site/
│   └── dist/                 # 静态部署版本（含 index.html、vendor、data、photos）
│       ├── index.html        # 与 VtW.html 同步的部署入口
│       ├── data/             # 世界/中国/日本都道府县边界、心愿圣地、季节美食数据
│       ├── photos/           # 心愿圣地本地实景图
│       └── vendor/           # Leaflet 离线静态资源
├── docs/                     # 使用说明与城市攻略索引
└── references/               # 参考网页与归档素材
```
